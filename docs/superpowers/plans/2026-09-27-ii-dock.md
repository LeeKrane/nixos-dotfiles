# Port the end4-pC Dock into ii — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the pinned illogical-impulse dock the fork's features (fullscreen autohide, drag-to-reorder pinned slots with window previews, a now-playing card, four show/hide options) as a four-patch `git format-patch` series in `patches/ii/03-dock/`.

**Architecture:** Four commits on the shared `krane` branch in `~/src/dots-hyprland`, after the tag `krane/02-translator`, exported to `patches/ii/03-dock/`. Sub-project 1's `iiSeries` loader in `lib/mk-host.nix` already applies every `patches/ii/*/` directory, so nothing in Nix changes. Patch 1 is a hand-port onto upstream `Dock.qml` and lands (committed, switched, checked) on its own; patches 2 to 4 are a snapshot port of the fork's files at `dc2ca26` with listed adaptations, and land together after the acceptance checks.

**Tech Stack:** Quickshell QML, Hyprland (`hyprctl`), git (`format-patch`, tags), nixpkgs `applyPatches`, Python 3 (edit scripts), curl.

**Spec:** `docs/superpowers/specs/2026-09-27-ii-dock-design.md`

## Assumed decisions

The spec's open questions, answered with its recommended defaults:

1. **Whole rewrite or only fixes:** all four patches, with the unpinned-preview regression fixed in patch 2.
2. **Declarative enable:** no Nix option. The dock is turned on once per host in Settings > Interface > Dock; `config.json` stays ii-owned.
3. **Defaults for the new options:** all four (`showBackground`, `showPinButton`, `showAppsButton`, `showMedia`) default `true`.
4. **DocktoPanel:** deferred to the settings or a bar sub-project.

Choices this plan makes where the spec leaves room (each is recorded in the patch's commit message):

- Separator visibility is rewritten from the fork's conditions so that no two separators touch and none trails at the end of the row, for every combination of pinned apps, running apps, media and the show options. The fork's conditions leave two adjacent separators when nothing is pinned or running.
- `DockMedia` is placed with `visible: Config.options.dock.showMedia && dockMedia.hasTrack`. The fork's `visible: Config.options.dock.showMedia` in `Dock.qml` overrides the card's own `visible: root.hasTrack`, so the card's slot stays when nothing is playing.
- The separator before the running apps uses `activeAppsArea.hasActiveUnpinned` (which includes the visible media card), not the fork's `MprisController.activePlayer !== null`, which is true for a player with no track.
- `DockMedia`'s download uses `curl -4`, the exact command upstream `PlayerControl.qml` uses, as the spec requires ("the same `curl`").
- `fullscreenOnThisMonitor` has an explicit `!!hyprMonitor &&` guard in addition to the spec's optional chaining, because `ws.monitor?.name === hyprMonitor?.name` is `undefined === undefined` (true) for a workspace without a monitor while `hyprMonitor` is null.
- If previews fail for unpinned apps while nothing is pinned, the first fallback (Task 2, Step 9) keeps `DragApps` visible at zero width, so its popup stays alive without restructuring the snapshot. The spec lists this as the first fallback and the move of the popup into `Dock.qml` as the second; the move rewrites the snapshot's popup ownership, so if the zero-width fallback also fails, stop and report instead of improvising it.
- The fork's dead `Layout.rightMargin: 10` on the anchored `activeRow` and `Layout.leftMargin` on the hidden apps separator are dropped (a `Layout.*` on a non-layout child or a hidden layout item has no effect).
- Fast iteration runs the patched ii from a scratch copy (`qs -p`) instead of switching, so nothing is written into `~/.config/quickshell`. Every acceptance check is repeated on the switched system in Task 6.

## Review Focus

1. **Unpinned previews with nothing pinned.** With `pinnedApps` empty, `DragApps` is hidden, yet its popup must still show previews for running unpinned apps. Expected: previews appear, centred over the icon (Task 2, Step 8; fallback Step 9).

4. **Separator combinations.** With nothing pinned, nothing running, no media, or with the pin or apps button hidden, expected: never two adjacent separators and never one at either end (Task 4, Step 5).
5. **Media edge cases.** A player with no track, one with a `file://` cover, and a stopped player. Expected: the card and its separator appear only with a track, the local cover shows without a download, and stopping hides both (Task 3, Step 5).

```bash
cd ~/src/dots-hyprland/dots/.config/quickshell/ii

from pathlib import Path

def sub(path, old, new):
    p = Path(path)
    s = p.read_text()
    assert s.count(old) == 1, f"{path}: expected exactly one match for {old[:60]!r}"
    p.write_text(s.replace(old, new))

"""            property bool reveal: root.pinned || (Config.options?.dock.hoverToReveal && dockMouseArea.containsMouse) || dockApps.requestDockShow || (!ToplevelManager.activeToplevel?.activated)
```
